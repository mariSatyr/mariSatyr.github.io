Hess's Law Lab

Hess's Law says the total enthalpy change (ΔH) of a reaction is the same no matter what path you take. So if you can't measure a reaction directly, you can build it out of other reactions — and just add up their ΔH values.

Try it: press Reverse
If ice melting absorbs heat, then water freezing must release the same amount.

The three moves

⇄

Reverse it → flip the sign

Write the equation backwards (reactants become products). ΔH stays the same size but changes sign.

A → B, ΔH = −50 kJ becomes B → A, ΔH = +50 kJ

×2

Multiply it → multiply ΔH

Multiply every coefficient by the same number. Multiply ΔH by that number too.

A → B, ΔH = −50 kJ becomes 2A → 2B, ΔH = −100 kJ

+

Add them → things cancel

Add the equations together. Anything on both sides cancels out. Add the ΔH values to get the answer.

(A → B) + (B → C) gives A → C

Exothermic: ΔH is negative

The reaction releases heat. The surroundings get warmer.

Examples: burning fuel, hand warmers, water freezing.

Endothermic: ΔH is positive

The reaction absorbs heat. The surroundings get colder.

Examples: cold packs, ice melting, photosynthesis.
