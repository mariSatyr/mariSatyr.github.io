# Deep Time Explorer — Image Sources

24 images, one per unique subject on the site. All were found on Wikimedia Commons (via Wikipedia / Commons) and license-checked on the Commons file page (API `extmetadata`) before downloading, 2026-11-16. All files are JPEG, max 1600 px on the longest side, quality 82.

**Licences:** 15 images are Public Domain or CC0 — no attribution required. 9 images are CC-BY / CC-BY-SA — they **must** be credited as shown if the site is published/shared. See "Attribution summary" at the end.

**Note on the site as supplied:** the site's current "images" are inline SVG doodles (hero gradients, pin icons, specimen shapes). There is no photo file to replace 1-to-1. `MAPPING.md` in this folder says which photo goes with each hero pin and each specimen-gallery item, so whoever edits the HTML can swap the SVGs for these files.

## Caveats

- **Eukaryote cells:** *Grypania* is a ribbon fossil, not a microscope photo of cells; no better PD/CC0 microscope image of a Proterozoic eukaryote was found.
- **Snowball Earth:** artist's impression, not a photograph.
- **Spriggina:** the frame also shows two *Dickinsonia* specimens and museum labels; the *Spriggina* is at upper left.
- **Small shelly fossils:** a published SEM figure, only 590 × 484 px — soft if shown large. It was the only genuine small-shelly-fossil image on Commons.
- **Steam cloud:** a modern volcano (Mount Redoubt) used as a stand-in for Hadean steam condensing into the first oceans.
- **Hazy orange sky:** NASA artist impression of Archean Earth from space, used for the hazy-sky pin.
